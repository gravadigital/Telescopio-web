# Task S-001.2: Unificar UI de Registro y Subida de Archivos en EventDetailPage

## Status

**Completed**

## Description

Modificar el componente `EventDetailPage` para unificar la experiencia de registro y subida de archivos en una sola vista cuando el evento está en etapa `participation`. Los participantes deben poder registrarse y, una vez registrados, ver inmediatamente la opción de subir archivos sin que el organizador tenga que avanzar a otra etapa.

Esta es la tarea más importante del frontend ya que implementa la nueva experiencia de usuario unificada que es el objetivo principal de la story.

**Conexión con Story**: Esta tarea implementa los criterios de aceptación CA2, CA3, CA4 y CA7 de la story S-001.

## Acceptance Criteria

1. Cuando el evento está en etapa `participation` y el usuario no está registrado, se muestra el botón "Participar" para registrarse.

2. Después de registrarse exitosamente, el usuario ve inmediatamente la sección de subida de archivos sin necesidad de recargar o esperar cambio de etapa.

3. La subida de archivos es opcional - el usuario puede registrarse sin subir archivo inmediatamente.

4. Si el usuario ya está registrado y entra a un evento en etapa `participation`, ve directamente la opción de subir archivos.

5. Las validaciones existentes se mantienen:
   - Solo usuarios registrados pueden subir archivos
   - Solo un archivo por participante
   - Tipos de archivo y tamaño permitidos se mantienen

6. Los mensajes de error y éxito son claros y apropiados para la nueva etapa.

7. La UI es responsive y mantiene la coherencia visual con el resto de la aplicación.

### 5. Actualizar handleRegister para refrescar el estado después del registro

```typescript
const handleRegister = async (): Promise<void> => {
  setLoading(true);
  setError('');
  setSuccess('');

  try {
    await EventService.registerParticipant(eventId, user!);
    setSuccess('¡Registrado exitosamente! Ahora puedes subir tu archivo.');
    setIsUserRegistered(true);
    
    // Actualizar el usuario en el contexto
    if (joinEvent) {
      joinEvent(eventId);
    }
    
    // Refrescar los detalles del evento
    await fetchEventDetails();
  } catch (err: any) {
    console.error('Error registering:', err);
    setError(err?.message || 'Error al registrarse. Intenta de nuevo.');
  } finally {
    setLoading(false);
  }
};
```
