# Task S-001.1: Actualizar Tipos TypeScript para Nueva Etapa

## Status

**Completed**

## Description

Actualizar la definición del tipo `EventStage` en el archivo `types/index.ts` para reflejar la nueva etapa unificada `participation` que reemplaza a `registration` y `attachment_upload`.

Esta tarea es fundamental ya que establece los tipos correctos que TypeScript utilizará para validar el código en toda la aplicación frontend. Actualizar estos tipos primero previene errores de compilación en las siguientes tareas.

**Conexión con Story**: Esta tarea implementa el criterio de aceptación CA1 de la story S-001 en el frontend.

## Acceptance Criteria

1. El tipo `stage` en la interface `Event` se actualiza para usar `'participation'` en lugar de `'registration'` y `'attachment_upload'`.

2. El tipo resultante es: `stage: 'creation' | 'participation' | 'voting' | 'results'`.

3. Se actualizan todas las funciones helper que mapean nombres de etapas (como `getStageDisplayName`) si existen.

4. El código de TypeScript compila sin errores después de los cambios.

5. No quedan referencias a los tipos `'registration'` o `'attachment_upload'` en el archivo de tipos.
