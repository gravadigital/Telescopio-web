# Task S-001.3: Actualizar Componentes de Listado y Visualización

## Status

**Completed**

## Description

Actualizar los componentes que muestran listados de eventos y permiten la gestión de etapas para reflejar la nueva etapa `participation`. Esto incluye actualizar botones, etiquetas, transiciones de etapa y textos en la interfaz de usuario.

Esta tarea asegura que toda la aplicación frontend sea consistente con el nuevo modelo de etapas, completando la implementación de la interfaz de usuario.

**Conexión con Story**: Esta tarea implementa los criterios de aceptación CA1, CA6 y CA7 de la story S-001.

## Acceptance Criteria

1. El componente `Events.tsx` muestra el botón correcto según la etapa del evento:
   - Etapa `participation`: Botón "Participar"
   - Otras etapas: Botones apropiados

2. El componente `ManageEventPage.tsx` permite transiciones correctas:
   - De `creation` a `participation`
   - De `participation` a `voting`

3. El componente `EventDetail.tsx` (si se usa) está actualizado con las nuevas etapas.

4. Todos los textos y mensajes reflejan la nueva terminología de "Participación".

5. No quedan referencias visuales a las etapas antiguas `registration` o `attachment_upload`.

6. El código compila sin errores de TypeScript.

7. La navegación entre componentes funciona correctamente con las nuevas etapas.

**Archivo:** `src/pages/manage-event/ManageEventPage.tsx`

  const stageNames: Record<string, string> = {
    creation: 'Creación',
    participation: 'Participación',
    voting: 'Votación',
    results: 'Resultados'
  };
