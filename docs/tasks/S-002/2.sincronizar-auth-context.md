# Task S-002.2: Sincronizar Eventos en AuthContext

## Status

**Completed**

## Description

Implementar la función `syncUserEvents()` en el AuthContext que consulta el backend y actualiza el localStorage con los eventos correctos del usuario.

## Acceptance Criteria

1. Existe la función `syncUserEvents()` en AuthContext
2. Se llama automáticamente después del login exitoso
3. Se llama al cargar la app si hay usuario en localStorage
4. Actualiza `user.joinedEventIDs` correctamente
5. Maneja errores sin romper la aplicación

## Technical Details

**Archivo a Modificar:**
`src/context/AuthContext.tsx`

```typescript
const syncUserEvents = async (): Promise<void> => {
  if (!user) return;
  
  try {
    console.log('🔄 Syncing user events from backend...');
    const userEvents = await UserService.getUserEvents(user.id);
    const eventIds = userEvents.map(e => e.id);
    
    // Update user with synced event IDs
    const updatedUser = { ...user, joinedEventIDs: eventIds };
    setUser(updatedUser);
    setItem(TELESCOPIO_USER_KEY, JSON.stringify(updatedUser));
    
    console.log('✅ User events synced:', eventIds.length, 'events');
  } catch (err) {
    console.error('❌ Failed to sync user events:', err);
    // Don't throw - fail silently and use localStorage as fallback
  }
};

// Call after successful login
const login = (userData: User, token: string): void => {
  setUser(userData);
  setToken(token);
  setItem(TELESCOPIO_USER_KEY, JSON.stringify(userData));
  setItem(TELESCOPIO_TOKEN_KEY, token);
  
  // Sync events from backend
  syncUserEvents();
};

// Call on app load
useEffect(() => {
  const storedUser = getItem(TELESCOPIO_USER_KEY);
  const storedToken = getItem(TELESCOPIO_TOKEN_KEY);
  
  if (storedUser && storedToken) {
    setUser(JSON.parse(storedUser));
    setToken(storedToken);
    
    // Sync events from backend after loading from localStorage
    syncUserEvents();
  }
  
  setLoading(false);
}, []);
```
