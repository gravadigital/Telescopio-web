# Task S-003.1: Actualizar Tipos TypeScript y Configuración API

## Status

**Completed**

## Description

Actualizar la interface `Event` en TypeScript para incluir los nuevos campos de fecha estimativa, y agregar el nuevo endpoint de edición de fechas a la configuración de la API.

Esta tarea es fundamental ya que establece los tipos correctos que TypeScript utilizará para validar el código en toda la aplicación frontend.

**Conexión con Story**: Esta tarea prepara la base de tipos para implementar los criterios de aceptación de la story S-003.

## Acceptance Criteria

1. La interface `Event` en `src/types/index.ts` incluye dos nuevos campos:
   - `participation_estimated_end_date?: string | null`
   - `voting_estimated_end_date?: string | null`

2. Se agrega el nuevo endpoint `EVENT_ESTIMATED_DATE` a `API_CONFIG.ENDPOINTS` en `src/config/api.ts`.

3. Se agrega el nuevo endpoint a la interface `ApiConfig` en `src/types/index.ts`.

4. El código de TypeScript compila sin errores después de los cambios.

Agregar al objeto `ENDPOINTS`:


**Agregar en ENDPOINTS:**
