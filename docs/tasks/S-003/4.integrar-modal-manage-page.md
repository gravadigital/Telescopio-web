# Task S-003.4: Integrar Modal en ManageEventPage

## Status

**Completed**

## Description

Integrar el componente `StageAdvanceModal` en la página de gestión de eventos para que se muestre al hacer clic en "Advance Stage". También agregar un botón para editar la fecha estimativa cuando el evento está en las etapas `participation` o `voting`.

**Conexión con Story**: Esta tarea implementa los criterios de aceptación CA1 (modal de confirmación) y CA5 (edición de fechas) de la story S-003.

## Acceptance Criteria

1. Al hacer clic en "Advance to [Stage]", se abre el `StageAdvanceModal` en lugar de cambiar directamente la etapa.

2. Cuando el usuario confirma en el modal, se llama a `updateEventStage` con la fecha si corresponde.

3. En las etapas `participation` y `voting`, se muestra la fecha estimativa actual en la sección de información.

4. Se agrega un botón "✏️ Edit Deadline" que abre un modal para editar la fecha.

5. El modal de edición utiliza el método `updateEstimatedEndDate` del servicio.

6. Si hay error al editar (ej: intentar adelantar fecha), se muestra el mensaje de error.

7. Después de cambiar la etapa o editar la fecha, se refresca la información del evento.

### 5. Agregar helper para formatear fecha con tiempo relativo

```tsx
const formatEstimatedDate = (dateString: string): string => {
  const date = new Date(dateString);
  const today = new Date();
  today.setHours(0, 0, 0, 0);
  date.setHours(0, 0, 0, 0);
  
  const diffTime = date.getTime() - today.getTime();
  const diffDays = Math.ceil(diffTime / (1000 * 60 * 60 * 24));
  
  const formattedDate = date.toLocaleDateString('en-US', {
    year: 'numeric',
    month: 'long',
    day: 'numeric'
  });
  
  let relative = '';
  if (diffDays === 0) {
    relative = '(today)';
  } else if (diffDays === 1) {
    relative = '(tomorrow)';
  } else if (diffDays > 1) {
    relative = `(in ${diffDays} days)`;
  } else if (diffDays === -1) {
    relative = '(yesterday)';
  } else {
    relative = `(${Math.abs(diffDays)} days ago)`;
  }
  
  return `${formattedDate} ${relative}`;
};
```

### 8. Crear componente simple EditDeadlineModal (inline o separado)

```tsx
// Puede ser un componente inline simple o reutilizar el modal existente
const EditDeadlineModal: React.FC<{
  stage: 'participation' | 'voting';
  currentDate?: string | null;
  onConfirm: (newDate: string) => Promise<void>;
  onCancel: () => void;
  isLoading: boolean;
}> = ({ stage, currentDate, onConfirm, onCancel, isLoading }) => {
  const [newDate, setNewDate] = useState(currentDate || '');
  const [error, setError] = useState('');

  const minDate = new Date().toISOString().split('T')[0];

  const handleConfirm = async () => {
    setError('');
    try {
      await onConfirm(newDate);
    } catch (err: any) {
      setError(err.message || 'Failed to update deadline');
    }
  };

  return (
    <div className="stage-modal-overlay" onClick={onCancel}>
      <div className="stage-modal" onClick={e => e.stopPropagation()}>
        <div className="stage-modal-header">
          <h2>Edit {stage === 'participation' ? 'Participation' : 'Voting'} Deadline</h2>
          <button className="stage-modal-close" onClick={onCancel}>×</button>
        </div>
        <div className="stage-modal-body">
          {currentDate && (
            <p className="current-date-info">
              Current deadline: <strong>{formatEstimatedDate(currentDate)}</strong>
            </p>
          )}
          <div className="stage-modal-date-field">
            <label>New Deadline<span className="required">*</span></label>
            <p className="field-hint">
              Note: You can only postpone the deadline, not bring it forward.
            </p>
            <input
              type="date"
              value={newDate}
              onChange={(e) => setNewDate(e.target.value)}
              min={minDate}
              disabled={isLoading}
            />
          </div>
          {error && <div className="stage-modal-error">⚠️ {error}</div>}
        </div>
        <div className="stage-modal-footer">
          <button className="btn btn-secondary" onClick={onCancel} disabled={isLoading}>
            Cancel
          </button>
          <button 
            className="btn btn-primary" 
            onClick={handleConfirm} 
            disabled={isLoading || !newDate}
          >
            {isLoading ? 'Updating...' : 'Update Deadline'}
          </button>
        </div>
      </div>
    </div>
  );
};
```
