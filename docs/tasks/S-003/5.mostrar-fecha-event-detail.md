# Task S-003.5: Mostrar Fecha Estimativa en EventDetailPage

## Status

**Completed**

## Description

Modificar la página de detalle del evento (`EventDetailPage`) para mostrar la fecha estimativa de cierre de la etapa actual. Esta información es visible tanto para organizadores como para participantes.

**Conexión con Story**: Esta tarea implementa los criterios de aceptación CA4 (visualización en detalle) y CA8 (visibilidad para todos los roles) de la story S-003.

## Acceptance Criteria

1. En la sección "Event Info", se muestra la fecha estimativa de cierre si existe para la etapa actual.

2. Se muestra solo cuando:
   - El evento está en etapa `participation` y tiene `participation_estimated_end_date`
   - El evento está en etapa `voting` y tiene `voting_estimated_end_date`

3. Formato de visualización: "October 15, 2026 (in 5 days)" con tiempo relativo.

4. El tiempo relativo se actualiza correctamente:
   - Futuro: "(in X days)" o "(tomorrow)" o "(today)"
   - Pasado: "(X days ago)" o "(yesterday)"

5. Se muestra un ícono de calendario (📅) junto al label "Stage Deadline:".

6. La información es visible para todos los usuarios autenticados (organizadores y participantes).

7. Si no hay fecha estimativa para la etapa actual, no se muestra nada (no mostrar "N/A").

### 1. Agregar helper para formatear fecha con tiempo relativo

Agregar esta función dentro del componente o como utilidad:

```tsx
const formatEstimatedDate = (dateString: string): string => {
  const date = new Date(dateString);
  const today = new Date();
  
  // Normalizar a medianoche para comparación de días
  today.setHours(0, 0, 0, 0);
  const targetDate = new Date(date);
  targetDate.setHours(0, 0, 0, 0);
  
  const diffTime = targetDate.getTime() - today.getTime();
  const diffDays = Math.round(diffTime / (1000 * 60 * 60 * 24));
  
  // Formatear la fecha
  const formattedDate = date.toLocaleDateString('en-US', {
    year: 'numeric',
    month: 'long',
    day: 'numeric'
  });
  
  // Calcular texto relativo
  let relative = '';
  if (diffDays === 0) {
    relative = '(today)';
  } else if (diffDays === 1) {
    relative = '(tomorrow)';
  } else if (diffDays > 1) {
    relative = `(in ${diffDays} days)`;
  } else if (diffDays === -1) {
    relative = '(yesterday)';
  } else {
    relative = `(${Math.abs(diffDays)} days ago)`;
  }
  
  return `${formattedDate} ${relative}`;
};
```

### 2. Agregar helper para obtener fecha de la etapa actual

```tsx
const getCurrentStageDeadline = (): string | null => {
  if (!event) return null;
  
  if (currentStage === 'participation' && event.participation_estimated_end_date) {
    return event.participation_estimated_end_date;
  }
  
  if (currentStage === 'voting' && event.voting_estimated_end_date) {
    return event.voting_estimated_end_date;
  }
  
  return null;
};
```

### 5. Opcional: Agregar clase dinámica según urgencia

```tsx
const getDeadlineCardClass = (): string => {
  const deadline = getCurrentStageDeadline();
  if (!deadline) return 'info-card deadline-card';
  
  const date = new Date(deadline);
  const today = new Date();
  today.setHours(0, 0, 0, 0);
  date.setHours(0, 0, 0, 0);
  
  const diffDays = Math.round((date.getTime() - today.getTime()) / (1000 * 60 * 60 * 24));
  
  if (diffDays < 0) {
    return 'info-card deadline-card urgent'; // Pasó
  } else if (diffDays === 0) {
    return 'info-card deadline-card today'; // Hoy
  } else if (diffDays <= 2) {
    return 'info-card deadline-card urgent'; // Próximo
  }
  
  return 'info-card deadline-card';
};

// Uso:
<div className={getDeadlineCardClass()}>
```
